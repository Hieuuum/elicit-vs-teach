Five frozen circuit tests

TestPasses when
SufficiencyThe circuit alone recovers more behavior (f) than random same-size circuits
EquivalenceWith only the circuit live, leftover KL is within 10% of the full model’s gap
Partial necessityRemoving the circuit hurts more than removing random same-size sets
ConsistencyEach problem’s own circuit covers ≥ 70% of the shared circuit
SpecificityRemoving the circuit hurts addition ≥ 3× more than a copy task

f = share of the model’s behavior the circuit alone recovers, in KL: 0 = none, 1 = all.

Random sets: 100 per size for children, 50 for parents. Tests frozen 2026-10-01.

Random circuits score f of about zero by construction: a random edge set almost never contains a full path from the embedding to the logits. So from 0.1% up sufficiency and partial necessity are easy passes; below that (20–39 edges, 2026-10-28) the circuit alone also scores f = 0, ties with random, and fails sufficiency, while partial necessity still passes; the informative tests are equivalence, consistency and specificity, plus the raw f values. Consistency also requires that ablating the shared edges beats random; that half passes everywhere, the coverage half is what fails.
