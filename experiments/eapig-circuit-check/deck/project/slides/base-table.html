Ranges are basic (reflected) bootstrap intervals, 200 resamples of the 512 NL prompts, one draw shared by all models; this interval type was chosen before the data because resampled top-k overlap is biased low. A basic interval need not contain the point (e.g. base → elicit child at 5%: 0.228 with 0.229–0.241). They cover prompt sampling only, not training-run variation. Reference rows reproduce the earlier overlap table exactly.
