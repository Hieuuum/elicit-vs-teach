The base TinyStories-1B model is the common ancestor of all four models. It was scored with the same KL EAP-IG on the same 512 NL prompts. Its circuit shares 0.20–0.34 of edges with the elicit child and 0.21–0.37 with the teach child: far above chance (8–100×), so shared pretrained plumbing gives a floor of about 0.2. Any two arithmetic-tuned relatives share about 0.3 (format parent → teach child, the control, elicit parent NL → elicit child). The elicit op-form parent → child pair, 0.50–0.77, is far above both tiers at every size. The teach child shares more with its format parent than with the base (by 0.04–0.10 from 0.2% up), but no more than with the unrelated control parent. The base's own split-half ceiling is the lowest of all models from 0.5% up (0.48–0.57), which explains part of its lower overlap; adjusted for ceilings, base → teach child sits only 0.02–0.09 below format parent → teach child.
