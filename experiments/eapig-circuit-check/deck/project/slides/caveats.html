Caveats

  • Random circuits score f ≈ 0 by construction, so “beats random” (sufficiency, partial necessity) says little.
  • Elicit parent’s specificity pits op-form addition against an NL copy task. It is not comparable to the children’s.
  • One training seed per child, and accuracy differs (NL EM 0.99 vs 0.40), so child-vs-child f is not a matched comparison.
  • Format parent fails the KL gate: its circuit is reproducible (ceiling 0.62–0.84) but carries almost no signal.
  • Children at 2–5% and functional shares at 2–5% come from the 2026-10-08 run (same frozen code and scores).
  • At 0.1%, own-circuit f ≤ 0.007 for both children, so functional shares there are noise.
